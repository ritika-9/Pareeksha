#  Exam Portal Backend

This project is the backend of an **Exam Portal** developed using **Spring Boot**, **Hibernate**, and **MySQL**. It provides functionalities for managing quizzes, user interactions, and administrative control.

## Features

- **Admin Dashboard:** Allows administrators to create and manage quizzes across multiple categories.
- **User Dashboard:** Users can attempt quizzes, receive immediate feedback, and see their scores after completing a quiz.
- **Seamless Integration:** Developed backend ensuring smooth integration with the frontend applications.

## 🛠Tech Stack

- **Backend Framework:** Spring Boot
- **ORM:** Hibernate
- **Database:** MySQL
